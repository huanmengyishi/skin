# v1.4 Repair Loop 收敛与停止策略

> 依据：Q1 三分类（Reference Fidelity=主 / Iteration Stability=辅 / Runtime Correctness=前置）不变。
> 本文件是停止条件唯一规范来源；实现于 src/generator/iterate.ts + src/generator/diagnosis.ts。

## 1. 迭代语义

iteration-0 = 首轮渲染+测量（无 repair 输入）；其后每轮 = repair 决策 → patch → 重建 → 重渲染 → 重测量。
maxIterations（默认 3）= **repair 轮数上限**；总渲染 ≤ maxIterations + 1。

## 2. No-repair 收敛（§33/§39）

iteration-0 测量后，若五维同时满足（默认阈值，可经 repairPolicy 配置）：

- pixel.diffRatio ≤ 0.02 且 region.meanDelta ≤ 12 且 palette.intersection ≥ 0.8 且 layout.cosine ≥ 0.9 且 structure.nonBlank

→ 诊断结论 = "无需修复"，状态 CONVERGED，不调用任何模型，直接进最终门。

## 3. 每轮状态判定（先验顺序）

| 状态 | 条件 | 动作 |
| --- | --- | --- |
| REGRESSED | 新 fidelity 任一主指标显著退化：region.meanDelta +10 以上、layout.cosine -0.05 以下、palette.intersection -0.1 以下、pixel.diffRatio +0.05 以上 | 停止；最终包 = 上一轮（最后非退化） |
| OSCILLATION | patch 后 spec 哈希已在 seenSpecHashes | 停止；最终包 = 上一轮 |
| UNCHANGED | 无有意义改善：palette.intersection 增量 <0.05 且 region.meanDelta 减量 <5 且 pixel.diffRatio 减量 <0.01 且 layout.cosine 增量 <0.05 | NO_IMPROVEMENT 停止 |
| CONVERGED | 有意义改善 且 轮间 diffRatio ≤ 0.02 且 渲染指纹不变 且 无退化 | 停止 |
| IMPROVED | 有意义改善但未达收敛 | 继续下一轮 |
| MAX_ITERATIONS | repair 轮数耗尽 | 停止（保留最后一轮有效包） |
| FAILED | 任一步失败（见失败域） | 停止；上一轮 Spec/Package 保持 |

阈值默认值全部可经 GenerationEnv.repairPolicy 覆盖；判定逻辑文档化，不做僵化总分数。

## 4. 多目标退化护栏（§26）

每轮 metricDelta 落盘：palette.intersection（+）/palette.dominantDistance（-）/layout.cosine（+）/region.meanDelta（-）/pixel.diffRatio（-）/structure.nonBlank（stable|changed）。
REGRESSED 判定见上表；结构变化（nonBlank true→false）= REGRESSED。

## 5. 振荡保护（§27）

- seenSpecHashes：本轮 patch 后 spec 的 sha256 与历史任一一致 → OSCILLATION。
- 同轮 repair 决策失败不计入历史；重问机会见 repair-decision 文档。

## 6. 修复预算（§28）

maxChangedFieldsPerIteration 默认 4（repairPolicy 可配）。超出 → 决策拒绝（不截断），走 REPAIR_DECISION 重问/停止路径。

## 7. Vision 二次观察策略（§22/§23/§53）

- 每轮取 rank=1 最差区域；同 regionId 已有 RegionEvidence（同 run）→ 复用，不重复调用。
- 裁剪：reference.png（1200×720 统一坐标系）bbox → pngjs 裁剪 → 最近邻 3× 放大（≤4MP 预算内）→ analyzeImage（VisionQueue 串行）。
- 429/视觉失败 → failureDomain=VISION_RECHECK，安全停止，上一轮包保持（vision-router 拥有 retry，dsh-skin 不叠加）。
- 区域证据经 toEvidence 归一化（V2），source/provenance 落盘（V3）。

## 8. 性能与成本（§52）

每轮记录：repairRounds、visionCalls（含缓存命中）、deepseekCalls、durationMs。报告如实给出每样本统计。

## 附录 A：页面区域几何（壳 mock 固定布局，cell→区域映射）

1200×720 视口；8×8 格每格 150×90：
- x<220（cell 列 0，部分列 1）：SIDEBAR（220px 侧栏）→ sidebarStyle/headerStyle/typography/colorPalette/spacing/backgroundStyle
- x≥220 且 y≥500（行 5~7 的 conversation 底部）：INPUT（输入区在会话区末尾）→ inputStyle/buttonStyle/borderStyle/spacing.radius/colorPalette
- x≥896 且 y<200（行 0~2）：OVERLAY（右上 280px 弹层）→ cardStyle/borderStyle/shadowStyle/colorPalette
- 其余：CONVERSATION → cardStyle/messageStyle/backgroundStyle/typography/colorPalette
- 全局候选（palette/layout 指标最差时）：PALETTE→colorPalette；LAYOUT→spacing.{density,radius}+backgroundStyle+shapeLanguage

候选字段只作提示输入；最终修改由 DeepSeek 决策（§12/§13）。
